# Company Financial Performance Analysis

## Project Overview
An end-to-end financial data analytics project focused on evaluating company revenue, expenses, profitability, regional performance, and monthly financial trends using Excel, MySQL, and Power BI.

## Tools & Technologies
- **Microsoft Excel:** Data cleaning and preparation
- **MySQL:** SQL queries and financial analysis
- **Power BI:** Interactive dashboard development
- **GitHub:** Project documentation and version control

## Project Workflow
1. **Data Cleaning:** Removed duplicate transactions, handled missing values, standardized inconsistent text entries, and prepared the dataset.
2. **SQL Analysis:** Used MySQL to calculate financial KPIs and investigate business performance.
3. **Power BI Dashboard:** Developed a three-page interactive dashboard to present financial insights.

## Key Performance Indicators

| Metric | Result |
|---|---:|
| Total Revenue | ₹1,62,86,734.75 |
| Total Expenses | ₹65,43,181.64 |
| Net Profit | ₹97,43,553.11 |
| Net Profit Margin | 59.83% |
| Total Transactions | 8,000 |

## Dashboard Pages
1. **Financial Overview:** Revenue, expenses, net profit, profit margin, and monthly trends.
2. **Revenue & Profitability:** Revenue by region, product contribution, and monthly revenue trends.
3. **Expense Analysis:** Department expenses, monthly expense trends, and expense distribution.

## SQL Analysis
The project includes 10 business-focused SQL analyses covering:
- Revenue and expense calculations
- Net profit and profit margin
- Monthly financial performance
- Department-wise expenses
- Product contribution
- Regional revenue performance
- Monthly profit trends and percentage changes

## Key Business Insights
- Total revenue was approximately ₹1.63 crore.
- Net profit was approximately ₹97.44 lakh.
- The overall net profit margin was 59.83%.
- January 2024 recorded the highest monthly profit.
- Monthly profits remained positive throughout the analysis period.
